# FAN DOTA2 — Python-версия задания

Оконное учебное приложение на Python и Tkinter. Данные сохраняются в SQLite.
Это самостоятельная программа, не конфигурация 1С. Для сдачи именно в 1С
нужно отдельно согласовать с преподавателем замену платформы.

## Запуск в Windows

1. Установите Python 3.10 или новее с компонентом Tcl/Tk.
2. На GitHub нажмите **Code → Download ZIP**, распакуйте архив полностью.
3. Откройте папку `python_app` и запустите `start.bat`.
   Или в терминале VS Code, находясь в папке репозитория:

```bat
py python_app/app.py
```

На macOS/Linux из папки `python_app`: `python3 app.py`.
В Linux может потребоваться системный пакет `python3-tk`.
Сторонних Python-библиотек и `pip install` не требуется.

При первом запуске создайте администратора: логин `Admin`, пароль придумайте
сами (от 8 символов). Готового общего пароля нет.
Откройте **Администрирование → Загрузить демо-данные**.

## Что реализовано

| Объект исходного задания | Реализация на Python |
|---|---|
| Информационная база | SQLite `fan_dota2.sqlite3` рядом с программой |
| Подсистемы | Вкладки окна |
| Перечисления | Фиксированные списки значений |
| Герои | Создание, изменение, удаление, поиск, атрибуты и таблица ролей |
| Предметы | Поля цены и признаков, категории верхнего уровня |
| Игроки | Ник, роль, стиль, комментарий |
| Сборки | Герой, стиль, роль, ситуация и таблица слотов 1–6 |
| Матч | Дата, сторона, победа, длительность, патч, участники и покупки |
| Проведение | Включение матча в отчёты, отмена проведения |
| СтатистикаГероя | Вычисление игр, побед, винрейта и среднего KDA по герою и игроку |
| ПокупкиВМатчах | Вычисление количества покупок по предмету, герою и игроку |
| ЗагрузкаДанныхDOTA2 | Идемпотентная загрузка демо + импорт JSON |
| Калькулятор | Фильтр героя и стиля, слоты, стоимость, подсказки |
| Отчёты | Винрейт, популярные предметы, сборки по стилю; экспорт CSV |
| Роли пользователей | Admin и Player; пароли PBKDF2 с индивидуальной солью |
| Стиль | Тёмные панели, золотые кнопки, цвет атрибутов и сторон |

Справочники хранятся как проверяемые JSON-записи в SQLite. Регистры заменены
вычисляемыми отчётами по проведённым документам: повторное проведение не
дублирует статистику, отмена немедленно исключает документ. Категории предметов
представлены списком групп одного уровня; произвольные вложенные группы и
опциональный справочник способностей не реализованы.

## Проверочный сценарий

1. Загрузите демо. Появятся 25 героев, 12 предметов, 3 сборки и игрок «Я».
2. В сборках выберите `PA Crit` → **Изменить**: таблица содержит 6 слотов.
3. В калькуляторе выберите `Phantom Assassin` и `Крит` → **Рассчитать**.
   Стоимость учебного примера: **22350** золота.
4. В **Матчи → Добавить** задайте название и длительность 40 минут.
5. Во вкладке **Участники → Добавить** выберите «Я», Phantom Assassin,
   Carry, 10 убийств, 2 смерти, 4 помощи, сборку PA Crit.
6. Во вкладке **Покупки → Добавить** выберите «Я», Daedalus и минуту 30.
7. Сохраните матч, выделите его и нажмите **Провести**.
8. В отчётах нажмите **Обновить отчёты**: одна игра, одна покупка,
   KDA 7.0; при установленной победе — винрейт 100%.
9. Повторное проведение не меняет итоги. Отмена проведения убирает матч
   из отчётов. Для изменения проведённого матча сначала отмените проведение.

Участники — игроки **вашей стороны**, поэтому общий флаг победы относится ко
всем участникам. KDA матча = (убийства + помощи) / max(1, смерти).
Средний KDA — среднее этих значений, а не отношение сумм.

## Пользователи, данные и ограничения

Admin редактирует всё и добавляет пользователей. Player читает справочники,
создаёт и изменяет игроков, сборки и матчи, открывает отчёты. Это локальная
учебная защита: человек с прямым доступом к файлу SQLite может менять базу.

Поиск в каждой таблице фильтрует по отображаемым значениям; для предметов можно
ввести категорию, для героев — атрибут. Импорт JSON объединяет записи по ID:
совпадающие ID заменяются. Импорт атомарен и проверяет ссылки; ошибочный файл
не изменяет базу. Экспорт не содержит пароли. Чтобы сохранить также пользователей,
закройте приложение и скопируйте `fan_dota2.sqlite3`.

Демо-данные условные и не заявлены как актуальные для какого-либо патча.
HP и скорость 0 означают незаполненные учебные значения. Атрибуты, роли,
цены и сборки можно изменить вручную. Файл стратегии из ссылки в задании
не предоставлен: сборки составлены для демонстрации функций.
Valve/OpenDota API не используются. Игровые изображения не включены.

## Исходный код и тесты

- `app.py` — окно, формы, таблицы и команды.
- `model.py` — проверка данных, SQLite, права и отчёты.
- `demo.py` — учебные данные.
- `test_model.py` — 8 автоматических тестов.

```bash
cd python_app
python -m unittest -v
```

Проверены загрузка без дубликатов, калькулятор, уникальность слотов, проведение
и отмена, ошибочные покупки, пароли и права, ссылки, атомарность импорта,
экспорт/импорт. Оконный интерфейс в среде без графического дисплея не был
интерактивно проверен; импорт Tkinter и компиляция Python проверены.
